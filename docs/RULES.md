# 十三支規則（本專案實作版）

規則以台灣常見玩法為底（中文維基「十三張」條目的「玩法 3」與「台灣玩法」），加上使用者指定的多副牌、鬼牌、五條。
**與傳統規則不同或自行訂定的地方，一律標「本專案」。**

## 1. 人數與牌

| 人數 | 牌副數 | 牌堆張數 | 每人 |
|---|---|---|---|
| 2 | 2 副 | 2 × (52 + 2 鬼) = 108 | 13 張 |
| 3 | 3 副 | 3 × 54 = 162 | 13 張 |
| 4 | 4 副 | 4 × 54 = 216 | 13 張 |

- 每副牌 52 張外加 2 張鬼牌；整堆洗勻後每人發 13 張（本專案：牌副數 = 人數）。
- 多副牌所以同一張牌（例如 ♠A）可能出現多張。
- **鬼牌可當任意一張牌**（任何點數、任何花色，包含和手上已有的牌重複）。系統自動把鬼牌當成「讓該墩牌型最大」的牌。

## 2. 擺牌

把 13 張牌排成三墩：**頭墩 3 張、中墩 5 張、尾墩 5 張**。

- 必須「**頭墩 < 中墩 ≤ 尾墩**」（比的是牌力，先比牌型再比點數）。違反 = **倒水**。
- **頭墩要嚴格小於中墩**：頭墩只有 3 張，跟 5 張的中墩比時，只比頭墩牌型「有的那幾張」——烏龍比最大 3 張、一對比（對子、踢腳）、三條只比點數；點數部分相同時，再比這 3 張牌的花色（見第 4 節「花色決勝」）。**點數與花色都相同**（只有多副牌才會有一模一樣的牌）才算平手，平手＝倒水。
  - 例：頭 A♣A♦K♥ 對中 A♠A♥K♦Q♣J♣：點數前 3 張相同，花色對子 ♠♥ > ♦♣ → 頭墩較小 → 合法。
  - 例：頭 A♣A♦K♥ 對中 A♦A♣K♥Q♣J♣：點數、花色都相同 → 平手 → 倒水。
  - 例：頭 A-A-K 對中 A-A-Q-J-9：點數頭墩較大 → 倒水（點數永遠先於花色）。
- 中墩與尾墩可以相等（同牌力不算倒水）。
- 頭墩只有三種牌型：烏龍、一對、三條（3 張不算順子與同花）。

## 3. 牌型大小（大 → 小）

| 名次 | 牌型 | 說明 |
|---|---|---|
| 1 | **五條** | 5 張同點數（本專案：多副牌 + 鬼牌才可能；依台灣五人玩法的「五龍」概念，排在同花順之上） |
| 2 | 同花順 | 5 張同花色連號 |
| 3 | 鐵支 | 4 張同點數 + 1 張 |
| 4 | 葫蘆 | 3 張同點數 + 一對 |
| 5 | 同花 | 5 張同花色 |
| 6 | 順子 | 5 張連號；A 可為最大（10-J-Q-K-A）或最小（A-2-3-4-5）；不能繞圈（Q-K-A-2-3 不算） |
| 7 | 三條 | |
| 8 | 兩對 | |
| 9 | 一對 | |
| 10 | 烏龍 | 無牌型 |

- 點數 A > K > Q > J > 10 > … > 2。同牌型比點數：由主要點數比起（例：葫蘆比三條那組點數，再比對子）。**點數完全相同才比花色**（見第 4 節）。
- 同花有重複點數也算同花（多副牌可能出現 A♠A♠K♠Q♠J♠）；同一手牌符合多種牌型時取最大者。
- 同花的點數比較：由大到小逐張比。

## 4. 花色決勝（Roy 指定，傳統十三支不比花色）

- 花色大小：**♠ 黑桃 > ♥ 紅心 > ♦ 方塊 > ♣ 梅花**。
- **點數優先**：牌型、點數（含踢腳）有任何差別，就由點數決定，花色不參與。
- **點數完全相同**時，依該牌型的「決勝順序」**逐張比花色**，第一張花色較大者勝；這一張相同再比下一張，以此類推：

| 牌型 | 決勝順序（每張牌先以點數、再以花色排序，同點數內花色大者在前） |
|---|---|
| 五條 | 五張依花色由大到小 |
| 同花順、順子 | 由頂牌往下（A-2-3-4-5 為 5-4-3-2-A） |
| 鐵支 | 四張同點數，再來踢腳 |
| 葫蘆 | 三條的三張，再來一對的兩張 |
| 同花 | 點數由大到小（同花的花色全相同，所以等於比花色本身） |
| 三條 | 三條的三張，再來踢腳 |
| 兩對 | 大對子兩張、小對子兩張，再來踢腳 |
| 一對 | 對子兩張，再來踢腳 |
| 烏龍 | 點數由大到小 |

- **鬼牌的花色**：同花／同花順中鬼牌必須是該花色；其他情況鬼牌自動當 ♠（最大）。
- 結果：兩手牌除非「點數與花色都一模一樣」（多副牌才可能），否則一定分得出勝負；平手墩只剩這種情形。

## 5. 比牌與計分

每兩位玩家之間，頭對頭、中對中、尾對尾，各墩分別比。

| 項目 | 分數 |
|---|---|
| 贏一墩 | +1（輸 −1，平手 0） |
| **打槍**：對同一人三墩全勝 | 該人基本分由 3 變 **6**（本專案採「基本分翻倍」版） |
| **全壘打**：打槍所有其他人（需 ≥3 人） | 每個對手的 6 再 ×2 變 **12** |
| **倒水** | 視為被所有未倒水的對手打槍（−6 + 對手額外加分）；兩人都倒水互不計分 |

### 額外加分（贏該墩者向輸家收，不受打槍／全壘打加倍）

| 墩 | 牌型 | 加分 |
|---|---|---|
| 頭墩 | 三條（衝三） | +1 |
| 中墩 | 葫蘆 | +1 |
| 中墩 | 鐵支 | +3 |
| 中墩 | 同花順 | +4 |
| 中墩 | **五條**（本專案） | +5 |
| 尾墩 | 鐵支 | +2 |
| 尾墩 | 同花順 | +3 |
| 尾墩 | **五條**（本專案） | +4 |

- 前六項取自維基「玩法 3」；五條加分是本專案依「同花順之上」延伸訂定的。
- 輸的一方不收加分（例如雙方尾墩都是鐵支，只有贏的那方的 +2 生效）。
- 分數為零和：所有人總分相加永遠 = 0。
- 網頁版再把每局分數乘上倍率換成籌碼，並以「任何人籌碼 ≤ 0 即整場結束」收尾，見 [SCORING.md](SCORING.md)；上面的分數規則本身不變。

### 本專案沒有實作的傳統內容

- 報到／特殊牌型（一條龍、三同花、三順子、六對半、四套三條、湊一色、全大、全小、十二皇族等）。
- 莊家制、下注與賠率（採人人對戰；網頁版以籌碼累計，見 SCORING.md）。
- 五人以上、對子同花（呸同）。
